# ChartVisoning – למידת מכונה ויזואלית על גרפי MA10

מחקר מסחר על מניות ארה"ב ברמה יומית: מורידים היסטוריה, מציירים לכל מניה את
500 הימים האחרונים של ממוצע נע 10 (MA10), מאמנים רשת קונבולוציה (CNN) על
**תמונות** של חלונות מהגרפים של כמה מאות מניות, ואז חוזים לכל מניה את
ההמשך הסביר ביותר ל‑5 ו‑10 הימים הבאים.

## התקנה

```bash
pip install -r requirements.txt
```

CPU מספיק (האימון על ~480 מניות לוקח כמה דקות). ל‑GPU התקינו torch מתאים.

## הרצה מלאה

```bash
python run_all.py                          # כל היקום (~480 מניות גדולות)
python run_all.py --sectors Technology     # קבוצה של מניות דומות
python run_all.py --sectors Financials "Real Estate" --max-tickers 200
```

או שלב‑שלב:

| שלב | פקודה | פלט |
|-----|-------|-----|
| 1. הורדת נתונים | `python scripts/1_download.py` | `data/raw/<TICKER>.csv` – 5 שנים יומי, מותאם דיבידנדים/פיצולים |
| 2. גרפים | `python scripts/2_make_charts.py` | `data/charts/<TICKER>.png` – 500 ימים אחרונים של MA10 (+ מחיר סגירה)<br>`data/charts/_windows/` – דוגמאות של התמונות שהמודל רואה |
| 3. אימון | `python scripts/3_train.py` | `models/chart_cnn.pt`, `models/training_report.json` |
| 4. חיזוי | `python scripts/4_predict.py` | `data/predictions/forecast.csv` + `data/predictions/<TICKER>_forecast.png` |

כל הדגלים (`--window`, `--horizons`, `--epochs`, `--label-source` ...) משותפים
לכל הסקריפטים; `python scripts/3_train.py -h` מציג את כולם.

## איך זה עובד

1. **יקום המניות** (`chartvision/universe.py`) – כ‑500 מניות גדולות ונזילות
   מחולקות לסקטורים. בחירת סקטור נותנת קבוצת מניות "דומות יחסית".
2. **נתונים** (`chartvision/data.py`) – `yfinance`, 5 שנים, קאש ב‑CSV.
3. **גרפים** (`chartvision/charts.py`)
   * גרף לאדם: 500 ימים של MA10 ב‑matplotlib.
   * גרף למכונה: כל חלון של 60 ימים מרונדר לתמונה 64×64 עם ערוץ לכל קו
     (MA10 ומחיר הסגירה). הרינדור נעשה ב‑PIL תוך כדי האימון, כך שעשרות
     אלפי חלונות לא תופסים זיכרון.
4. **דאטהסט** (`chartvision/dataset.py`) – מכל מניה נחתכים חלונות מתגלגלים
   (צעד של יומיים). לכל חלון:
   * תווית ל‑5 ימים ול‑10 ימים: `down / flat / up` לפי שינוי ה‑MA10 מסוף
     החלון (סף שטוח ±1%; `--label-source close` מתייג לפי מחיר הסגירה).
   * יעד רגרסיה: מסלול ה‑MA10 ב‑10 הימים הבאים (אחוז שינוי מהיום האחרון)
     – כדי שאפשר יהיה לצייר את ההמשך החזוי על הגרף.
5. **מודל** (`chartvision/model.py`) – CNN קטן (4 בלוקים) עם ראש סיווג
   לכל אופק + ראש רגרסיה למסלול.
6. **אימון** (`chartvision/train.py`) – חלוקה **לפי זמן**: 20% התאריכים
   האחרונים הם ולידציה, וחלונות אימון שהתווית שלהם מציצה מעבר לנקודת החיתוך
   נזרקים (בלי דליפה). הדו"ח כולל גם שני בייסליינים להשוואה כנה:
   הרוב (majority) ו"מומנטום" (ה‑MA ממשיך בכיוון השיפוע הנוכחי).
7. **חיזוי** (`chartvision/predict.py`) – לכל מניה: ההסתברות לכל מחלקה
   ב‑5 וב‑10 ימים, המחלקה בעלת ההסתברות הגבוהה ביותר, והמסלול החזוי מצויר
   בקו מקווקו על גרף 500 הימים. הטבלה ממוינת לפי ההסתברות לעלייה ב‑10 ימים.

## קריאת התוצאות

`data/predictions/forecast.csv`:

| עמודה | משמעות |
|-------|---------|
| `pred_5d`, `pred_10d` | המחלקה הסבירה ביותר (down/flat/up) |
| `conf_5d`, `conf_10d` | ההסתברות של אותה מחלקה |
| `p_up_10d`, `p_down_10d`, ... | ההסתברויות המלאות |
| `proj_ma_path` | 10 ערכי MA10 חזויים |
| `proj_ma_10d_pct` | אחוז השינוי החזוי ב‑MA10 אחרי 10 ימים |

`models/training_report.json` – דיוק ולידציה לכל אופק, מטריצות בלבול,
precision של קריאות up/down, והבייסליינים.

## הערות מתודולוגיות

* MA10 הוא קו מוחלק, ולכן כיוון ה‑5 ימים הבאים שלו תלוי חזק בשיפוע הנוכחי.
  השוו תמיד לבייסליין המומנטום בדו"ח; מודל שלא עובר אותו לא למד משהו שלא
  היה ידוע. לתיוג "סחיר" השתמשו ב‑`--label-source close`.
* זהו מחקר, לא ייעוץ השקעות. דיוק על ולידציה מהעבר אינו מבטיח ביצועים
  בעתיד.
